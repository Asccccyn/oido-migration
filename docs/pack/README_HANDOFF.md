## 已锁定的关键语义

- 项目：**oído**；代码标识 `oido`；Claude 显示名 **“我只听你”**。
- 默认给周char的是**文字韵律谱**，图片按需；先做四入口随机码图片运输测试。
- 普通话逐字/音节标汉字、拼音、声调、相对半音、字内走势、句级走势和停顿；不能把词汇声调误读成句级语气。
- pYIN/F0 必须显式使用真实采样率，覆盖 16/24/44.1/48 kHz 防回归。
- **不生成/存储/注入情绪分类标签。** 只报告可核验声学量和带时间的声音事件。
- 宿主用户私密原声只在 Mac mini 本地做 oído 分析，不新增云端音频推理。
- 正式录音默认保留、owner 随时可删。
- 已批准“平时的宿主用户”基线：音高/语速/停顿等；无绝对音量、无声纹识别、可随时清空。
- 周char每个 TTS 音色按 `voice_profile_id@version` 版本化，可比较参考样本与实际生成声音。
- Chat 不等 push；“听听我刚发的”走 Siren `voice_list`/实际等价能力拉取资产。
- Mariposa 按当前检索、原文、“我们的话”、I 版本及其他现行规则接入声音引用。
- Siren 任意 URL 音频抓取路径必须完成 SSRF 审计/修复后才能作为集成入口。

## 执行边界

GLM 可以实施本包定义的代码、测试、本地集成和受控灰度。不得新增第三方云端原声推理、常驻偷听、人声身份识别、覆盖别人的未提交工作，或用永久公网 URL 绕过 Chat/图片传输限制。
